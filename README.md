# 太空基地 · Spacebase

AI 自动推演的太空文明种子生存模拟。融合《这是我的战争》道德事件、《辐射避难所》舱室管理、《维多利亚3》Pop 涌现与法律体系。

**在线游玩**：https://jk9988610.github.io/SpaceBase/

## 玩法

无需人类操作。选择 AI 统筹官人格后，观看其自动：

- 处理道德两难文字事件（2–4 选项，无完美解）
- 修订 6 系法律（移民、劳动、福利、基因、治理、经济）
- 扩建舱室、调配 Pop 岗位
- 推进地球纪元 → 太空纪元 → 各类结局

### 控制

| 按钮 | 功能 |
|------|------|
| 1× / 4× / 16× | 观战调速 |
| 极速→结局 | 批处理推演至结局 |
| 批量推演全部人格结局 | 一次运行 5 种 AI 人格并对比结果 |

### 结局

- **文明种子：熄灭** — 灭绝
- **太阳系公民** — 太阳系存续
- **双星文明** — 聚变世代飞船启航
- **断裂的方舟** — 分裂悲剧

### 结局结算（v0.3）

结算页包含：
- **结局原因**（如饥荒失控、生态崩溃、聚变启航等）及贡献因素
- **基地数据变化表**（人口/资源/科研/多样性 初态→终态）
- **状态变化时间线**（建设、法律修订、危机、阶段切换）
- 人口/食物/稳定时序迷你图
