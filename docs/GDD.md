## 一、游戏概述

### 1.1 定位

即时制文字决策生存模拟。玩家**不直接操作**，而是观看 **AI 统筹官** 根据基地状态、Pop 群体态势与现行法律，自动做出政策与事件抉择，直至走向各类结局。

对标融合：
- 《这是我的战争》— 道德两难文字事件，无完美选项
- 《辐射避难所》— 舱室扩建、岗位匹配、资源闭环
- 《维多利亚3》— Pop 涌现模拟、**法律体系**、派系立场、历史因果

### 1.2 核心体验

| 角色 | 体验 |
|------|------|
| **观察者** | 调速观看 AI 推演，阅读事件叙事与决策理由 |
| **分析者** | 查阅档案面板，追踪法律变更如何滞后影响 Pop 与生态 |
| **复盘者** | 结局后阅读完整文明历史报告 |

### 1.3 设计铁律

```
AI / 玩家 ──只能──▶ 法律 · 舱室 · 岗位规则 · 移民政策 · 事件选项
                          │
                          ▼
                    Pop 实例 tick 运算
                          │
                          ▼ 聚合（只读）
                 统计面板 · 时间线档案 · 新事件触发
```

禁止直接修改全局「社会稳定」「科研点数」等抽象变量。

## 二、世界观背景

小行星将在 **50 年后**撞击地球。地球联盟建造分布式旋转圆筒 **太空基地（Spacebase）** 集群，保存文明种子。

### 阶段一：地球纪元（Y0–Y50）
- 地球联盟统筹全球资源，建造基地、选拔移民、开发小行星工业
- 首座基地入轨后分批输送移民；持续建造更多基地
- Y50 未达成生存目标 → 灭绝结局权重上升

### 阶段二：太空纪元（Y50+）
- 地球毁灭，补给永久归零
- 完全依赖太阳系资源：小行星采矿、冰体挥发物、太阳能
- 远期解锁比邻星世代飞船

## 三、底层模拟机制

### 3.1 时间系统

| 项目 | 设定 |
|------|------|
| 模式 | 即时制，支持暂停 / 1× / 4× / 16× / 极速批处理 |
| 基础单位 | 1 tick = 1 游戏日 |
| 聚合存档 | 每 30 tick 写入时间线快照 |

### 3.2 单 tick 顺序

```
① 舱室资源运算（产出、消耗、挥发物泄漏）
② 全部 Pop 独立逻辑（消耗、出生/死亡、士气/忠诚/激进）
③ 法律修正器应用
④ 聚合刷新统计面板 + 写入档案
⑤ 阈值检测 → 事件入队 → AI 立即裁决
⑥ AI 政策检查（法律修订、岗位调配、建设指令）
```

### 3.3 Pop 实例规则

同一基地内，**职业 + 资质 + 遗传分组 + 舱段 + 社会立场** 相同者合并为一个 Pop。

```
Pop {
  count, laborForce, dependents
  profession, skillTier, geneGroup, habitat, ideology
  morale, radicalism, loyalty          // 0–100
  birthRate, deathRate                 // 每 tick 动态计算
}
```

宏观指标全部由 Pop 聚合涌现：
- 总人口、基因多样性、社会稳定、出生/死亡率
- 科研进度 = Σ(科研 Pop × 资质 × 实验室效率)

## 四、法律体系（维多利亚3 式）

法律分 **6 大法系**，每系互斥多选一。修订法律是 AI 的核心决策之一，需消耗 **政治资本** 并可能引发派系反弹（Pop 激进度变化）。

### 4.1 移民政策 `immigration`

| 选项 | 效果摘要 |
|------|----------|
| 开放边境 | 多样性 +，资源消耗 +，忠诚 - |
| 精英筛选 | 资质均值 +，多样性 -，激进 + |
| 配额管制 | 平衡，政治资本消耗低 |
| 关闭边境 | 忠诚 +，多样性持续下降 |

### 4.2 劳动体制 `labor`

| 选项 | 效果摘要 |
|------|----------|
| 八小时制 | 士气 +，产出 - |
| 轮班加班 | 产出 +，死亡率 +，激进 + |
| 强制劳动 | 产出 ++，忠诚 --，人道事件权重 + |
| 岗位竞聘 | 资质匹配 +，失业 Pop 激进 + |

### 4.3 福利配给 `welfare`

| 选项 | 效果摘要 |
|------|----------|
| 按需分配 | 士气 +，消耗 + |
| 定额配给 | 平衡 |
| 功勋优先 | 科研/生产 Pop 忠诚 +，普通移民士气 - |
| 配给削减 | 资源节约，激进 ++ |

### 4.4 基因伦理 `genetics`

| 选项 | 效果摘要 |
|------|----------|
| 强制筛查 | 多样性长期 +，宗教派系激进 + |
| 自愿原则 | 宗教派系忠诚 +，近亲风险累积 |
| 基因优化 | 资质 +，伦理事件 +，激进 + |
| 禁止干预 | 多样性自然演化，医疗需求 + |

### 4.5 治理结构 `governance`

| 选项 | 效果摘要 |
|------|----------|
| 理事会共和 | 稳定，决策慢 |
| 技术官僚 | 科研 +，普通 Pop 疏离 |
| 紧急状态 | 建设速度 +，忠诚 -，法律修订容易 |
| 派系自治 | 忠诚分化，分裂风险 + |

### 4.6 资源经济 `economy`

| 选项 | 效果摘要 |
|------|----------|
| 计划经济 | 配给稳定，创新 - |
| 市场调剂 | 效率 +，波动 + |
| 配给券制 | 黑市事件 +，灵活性 + |
| 战时共产主义 | 危机产出 +，士气 -- |

### 4.7 法律修订机制（参考 V3）

- AI 累积 **政治资本**（来自稳定社会、档案中心、理事会支持）
- 修订法律：消耗资本，部分 Pop 意识形态支持/反对
- 反对派 Pop 激进度上升，可能触发「法案抵制」事件链
- 法律效果不直接改全局数，而是修改 Pop 运算中的 **修正器系数**

## 五、AI 自动推演系统

### 5.1 设计目标

无需人类点击选项。AI 统筹官根据：
1. 当前资源与生态压力
2. Pop 聚合指标（士气、激进、忠诚、多样性）
3. 现行法律与派系立场
4. 游戏阶段（地球纪元 / 太空纪元）
5. **AI 人格策略**

自动完成全部事件抉择、法律修订、建设与岗位调配，直至触发结局。

### 5.2 AI 人格策略

| 人格 | 优先权重 |
|------|----------|
| 生存优先 | 资源储备、生态闭环、配给 |
| 扩张优先 | 多基地、人口、采矿 |
| 人道主义 | 士气、福利、移民接纳 |
| 威权稳定 | 忠诚、激进压制、强制劳动 |
| 科技至上 | 研发、世代飞船、技术官僚 |

### 5.3 决策评分（事件 / 法律）

```
score(选项) = Σ(维度权重 × 归一化影响)
            + 人格偏好修正
            + 法律一致性加成
            + 随机扰动(±5%)
```

AI 选择最高分选项，并在 UI 展示：**选了什么 / 为什么 / 预计影响哪些 Pop**。

### 5.4 极速推演模式

批处理 tick 直至：下一事件、阶段切换、或结局。用于快速验证各结局路径。

## 六、核心玩法模块

### 6.1 舱室（基地模拟层）

| 舱室 | 岗位 | 产出 |
|------|------|------|
| 人居舱 | — | 居住容量；消耗能源、挥发物 |
| 闭环农业舱 | 生态工程师 | 食物、O₂ |
| 裂变能源舱 | 核运维 | 能源（辐射风险）|
| 小行星船坞 | 采矿技师 | 金属矿石 |
| 科研实验室 | 档案学者 | 研发贡献 |
| 医疗舱 | 医护 | 降死亡率 |
| 档案统计中心 | 档案学者 | 解锁深度报表 |
| 移民选拔中心 | 行政 | 地球纪元移民 |

### 6.2 核心资源

能源 · 生物质食物 · 金属矿石 · 挥发物（H₂O/N₂，持续泄漏）

### 6.3 文字事件层

- 2–4 选项，无完美解
- 效果作用于 Pop 实例或设置延迟修正器
- 全部带时间戳写入人文历史日志
- **由 AI 自动裁决**，UI 展示决策过程

### 6.4 历史-生态统计档案（只读）

1. **人口遗传学**：总人口、多样性、出生/死亡率曲线
2. **生态闭环**：氧碳平衡、泄漏率、农业波动
3. **科技统计**：各分支研发进度
4. **人文历史**：决策、法律、灾难、思潮变迁
5. **法律年表**：每次修订的时间、内容、派系反应

结局输出完整 **文明复盘报告**。

## 七、科技树与结局

### 7.1 远期科技

- 挥发物回收 · 抗污染农业 · 辐射屏蔽
- 核聚变推进 → **聚变世代飞船**（4 万人，4.2 光年）
- 核热慢速飞船（4000+ 年，低成功率）

### 7.2 结局

| ID | 名称 | 触发条件 |
|----|------|----------|
| extinction | 灭绝 | 人口归零 / 生态崩溃 / 倒计时失败 |
| solar | 太阳系存续 | 集群稳定 30 年，放弃或无力远航 |
| stellar | 星际启航 | 聚变飞船发射，母文明存续 |
| schism | 分裂悲剧 | 派系撕裂 + 强行核热发射 |
